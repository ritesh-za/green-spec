Plan, track, and ship — without leaving VS Code.

Todo Pilot is a VS Code extension that brings priority-driven task management, in-editor TODO scanning, team collaboration, and GitHub Copilot integration into your daily workflow. Your tasks live in your repo. No telemetry. Fully offline.

See pricing Install on VS Code Marketplace View on GitHub

What you get

Priority-first task list

P1 / P2 / P3 priorities, custom groups, drag-and-drop ordering, and a status bar widget.

Code TODO scanning

Find TODO, FIXME, HACK, NOTE, BUG across your workspace and jump straight to the line.

Promote scan hits to tasks

Right-click any code TODO and turn it into a tracked task with priority and group.

Team collaboration

Each teammate's tasks live in their own JSON file in the repo — no merge conflicts, no central server.

GitHub Copilot integration

Mention @todopilot in Copilot Chat or let Copilot agent mode add, list, and update tasks for you.

Fully offline

No telemetry. No account. License keys verify locally — your data stays on your machine.

How licensing works

After purchase you'll receive a license key by email (format TP-PRO-XXXXX-XXXXX-XXXXX). In VS Code, run Todo Pilot: Enter License Key… and paste the key. Pro features unlock immediately. Activation is fully offline — no network call, no telemetry.

Pro covers 1 machine; Team covers up to 3. To move machines, run Todo Pilot: View Plan → Deactivate License on the old machine and re-enter the key on the new one.
